# 讯飞语音识别 API 凭证获取指南（MC632X 语音控制用）

> 我们的代码 `xf_http_asr.c` 调的是讯飞**「语音听写」**服务的 **WebAPI（REST）** 端点
> `https://iat-api.xfyun.cn/v2/iat`。所以你要申请的不是"星火大模型"、也不是"实时语音转写"，
> 而是**「语音听写」**这个服务。下面是从零拿到 AppId / APIKey / APISecret 的完整步骤。

---

## 〇、先分清三个服务（别开错）

| 服务名 | 接口形态 | 我们要不要 |
|---|---|---|
| **语音听写** | WebSocket **或** WebAPI（REST） | ✅ 要，用它的 **WebAPI**（`iat-api.xfyun.cn`） |
| 实时语音转写（lfasr） | REST 长音频转写 | ❌ 不要 |
| 星火认知大模型 | 对话大模型 | ❌ 不要（那是聊天，不是 ASR） |

> 一句话：创建应用后，在应用里**开通「语音听写」**服务即可。

---

## 一、注册 & 实名认证（约 1 天）

1. 打开 **讯飞开放平台**：https://www.xfyun.cn/
2. 右上角「注册」，用手机号注册开发者账号。
3. 登录后做**实名认证**（个人实名即可，免费额度够测试）：
   - 控制台 → 右上角头像 → 「实名认证」
   - 个人认证填身份证；企业认证填营业执照。
   - ⚠️ 审核通常几小时~1 天，未实名很多服务开不了、调用也受限，**先做完这步**。

---

## 二、进入控制台

登录后点顶部 **「控制台」**，或直接访问：https://console.xfyun.cn/

（讯飞现在把很多能力收进了"星火"体系，但**语音听写这种老服务仍在开放平台控制台**，
入口就是上面的 `console.xfyun.cn`，不要迷路到星火对话台。）

---

## 三、创建应用

1. 控制台左侧 **「我的应用」** → 右上角 **「创建应用」**。
2. 填写：
   - **应用名称**：随便起，如 `MC632X工位检测终端`
   - **应用分类 / 平台**：选「其他」或「硬件 / 嵌入式」均可（不影响密钥）
   - **应用描述**：可留空或写用途
3. 点「提交」，**应用创建成功**。

> 创建成功后系统会生成一组凭证，它们**和应用绑定**，不是和服务绑定——
> 即同一个 AppId 下开通的不同服务，**共用同一组 APIKey / APISecret**。

---

## 四、开通「语音听写」服务并拿到三个凭证

**方式（当前控制台最常见路径）：**

1. 在「我的应用」里**点进刚创建的应用**，进入应用详情页。
2. 应用详情页**顶部**就能看到 **APPID**（一串数字，如 `6501a2xx`）。
3. 往下找 **「服务列表」/「已开通能力」**，找到 **「语音听写」**：
   - 若还没开通：点「+ 添加」/「开通」，搜"语音听写"→ 确认开通。
   - 已开通：点「语音听写」右侧的 **「控制台」** 或 **「管理」**。
4. 进入语音听写服务页后，页面上会显示 **APIKey** 和 **APISecret**：
   - 老版控制台：应用详情页直接并列显示 AppId / APIKey / APISecret。
   - 新版控制台：密钥在「语音听写」服务的「服务管理 / 鉴权信息」里。
   - 如果找不到，回到应用详情页点「**查看 APIKey / APISecret**」按钮。

> ⚠️ **APISecret 通常只显示一次**（创建或重置时），复制后妥善保存到本地。
> 忘了对应用户的「重置密钥」会生成新的，旧密钥作废。

**你最终要抄下这三样：**
```
AppId     = 6501a2xxxxxxxx   （纯数字）
APIKey    = xxxxxxxxxxxxxxxxxxxxxxxx
APISecret = xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx   （最长，最敏感）
```

---

## 五、把凭证填进代码（二选一）

**方式 A — 直接改宏（最简单，适合测试）：**
编辑 `voice_asr/xf_http_asr.h` 顶部：
```c
#define XF_APPID      "6501a2xxxxxxxx"
#define XF_API_KEY    "你的APIKey"
#define XF_API_SECRET "你的APISecret"
```

**方式 B — 运行时注入（推荐，避免硬编码进固件）：**
在 `demo_entry` 初始化时调用一次：
```c
xf_asr_set_credential("你的AppId", "你的APIKey", "你的APISecret");
```

---

## 六、免费额度与计费（心里有数）

- 语音听写有**每日免费调用额度**（具体次数以控制台「语音听写」服务页显示为准，常见是每天几百次）。
- 超出免费额度需**购买资源包**，否则返回配额错误码（如 `10105` 权限/配额类）。
- 阶段0 验证用免费额度足够，不必先花钱。

---

## 七、最容易踩的坑（对照排查）

| 现象 | 原因 | 解决 |
|---|---|---|
| 返回 `10105` / 鉴权失败 | APIKey/Secret 填错或应用未开通语音听写 | 核对三件套；确认服务已开通 |
| 返回时间相关错误（如 `AuthFailed`/date 偏差） | **板子没校时** | 上电先 `ntp_sync` 同步时间（代码签名用 RFC1123 date） |
| 返回音频格式错误 | 不是 16k/16bit/单声道 PCM | 用 `ffmpeg -ar 16000 -ac 1 -f s16le` 转 |
| 控制台找不到密钥 | 新版分服务，密钥在「语音听写」服务页 | 进服务管理页看「鉴权信息」 |
| 调用超时 | 以太网未 up / DNS 不通 | `ifconfig` 确认有 IP；确认能访问外网 |
| 创建专属节点后 host 变了 | 默认可用 `iat-api.xfyun.cn` | 若开了武汉/上海节点，改 `xf_http_asr.c` 里 `g_host`/`g_uri` |

---

## 八、安全提醒

- **APISecret 严禁写进公网仓库 / 开源代码**。量产建议：
  - 用方式 B 从配置文件 / NVS / 加密分区读取；
  - 或只烧录到设备本地，不进 git。
- 设备一旦丢失，去控制台「重置密钥」使旧密钥失效。
