# MC632X 语音识别 上板实操清单（以太网 + 讯飞 HTTP 一句话识别）

> 跟着勾选框走，从「代码已就绪」到「串口跑通 voice_test」共 7 大步。
> 前提：你已在 VM 里有可编译的 SDK 工作树（双摄+屏显+AI 已通的 `media_demo`），本机 `voice_asr/` 文件已生成且凭证已填。

---

## □ 第 0 步：确认环境
- [ ] VM 里 SDK 工作树路径记为 `$SDK`（例如 `D:\share\MC632X` 或 `~/MC632X`）
- [ ] `$SDK/app/media_demo/` 下能看到 `sample_demo/`、`lvgl_port/`、`script/`
- [ ] 本机 `voice_asr/` 含 7 个文件，且 `xf_http_asr.h` 三个宏已是 `bb9bda54` / `7bb43d8…` / `YWZhNDM0…`

把整目录 `voice_asr/` 拷进 `$SDK/app/media_demo/voice_asr/`，与 `lvgl_port/` 并列：

```
$SDK/app/media_demo/
```

## □ 第 2 步：menuconfig 开网络与加密库（`make appconfig`）

进图形菜单，逐层展开，把下面 ★ 项设为 `y`（按空格切换，行首出现 `[*]` 即开）：

```
[★] RT-Thread Components  →  Network
        [*]   Socket abstraction layer (SAL)              (RT_USING_SAL)
        [*]   Network interface device (netdev)           (RT_USING_NETDEV)
        [*]   light-weight TCP/IP stack (lwIP 2.1.2)      (一般默认已开)
        [*]   RT-Thread netutils  →  NTP (RFC1305)         (RT_USING_NETUTILS + NTP)  ← 校时需要

[★] RT-Thread Online Packages  →  misc packages
        [*]   mbedtls                              (PKG_USING_MBEDTLS)   ← TLS + HMAC-SHA256

[★] RT-Thread Online Packages  →  IoT
        [*]   libcurl                            (PKG_USING_LIBCURL)   ← HTTP 客户端
                (libcurl 的 TLS backend 选 mbedtls，不要选 openssl)

[ ] RT-Thread Components  →  Device virtual file system (DFS) + elmfat
        ← 仅"文件回退测试"需要；阶段0 用 /pcm_test.raw 测试时建议也开上
```

保存退出（选 `Save`，默认文件名 `.config`，回车；再 `Exit`）。

> 退出后第一遍 `make` 会自动 `pkgs --update` 拉取 mbedtls / libcurl 源码并下载。

## □ 第 3 步：改 `media.mk` 把源文件编进去

编辑 `$SDK/app/media_demo/script/rtt/chip/MC632X/media.mk`（不同版本路径可能略有差异，用 `find . -name media.mk` 定位），在末尾 SRC 段追加：

```makefile
# ============ 语音控制（以太网 + 讯飞 HTTP） ============
VOICE_DIR = $(LOCAL_DIR)/voice_asr
SRC += $(VOICE_DIR)/xf_http_asr.c
SRC += $(VOICE_DIR)/audio_capture.c
SRC += $(VOICE_DIR)/voice_cmd.c

# ============ LVGL 屏上 UI ============
LVGL_PORT = $(LOCAL_DIR)/lvgl_port
SRC += $(LVGL_PORT)/lv_port_disp.c
SRC += $(LVGL_PORT)/ui_display.c
SRC += $(shell find $(LVGL_PORT)/lvgl/src -name '*.c')

# ============ 头文件路径 ============
CFLAGS += -I$(VOICE_DIR)
CFLAGS += -I$(LVGL_PORT)
CFLAGS += -I$(LVGL_PORT)/lvgl
```

> 若构建系统不支持 `$(shell find ...)`，把 LVGL 的 `src` 下子目录（lv_core / lv_draw / lv_font / lv_gpu / lv_hal / lv_misc / lv_objx / lv_themes / lv_widgets）逐个用 `SRC += $(LVGL_PORT)/lvgl/src/xxx/*.c` 列出。
>
> 注意：`$(LOCAL_DIR)` 在本 mk 里应已定义为 `media_demo` 目录，若不是，请改用 `$(CURDIR)` 或相对路径确认一次。

## □ 第 5 步：NTP 自动校时（重要，省去每次手敲）

把下面片段加进初始化流程（在任何联网识别之前、netdev up 之后调用一次）：

```c
#include <ntp.h>          /* 来自 RT-Thread netutils 组件 */

static int board_ntp_sync(void)
{
    time_t t = 0;
    for (int i = 0; i < 5; i++)
    {
        t = ntp_sync(NULL);          /* 用默认 NTP 服务器，返回 epoch 秒 */
        if (t > 0) { set_time(t); break; }
        rt_thread_mdelay(1000);
    }
    return (t > 0) ? 0 : -1;
}
/* 调用示例：在 netif 拿到 IP 后 */
board_ntp_sync();
```

> 若你的 netutils 版本没有 `ntp_sync()`，改用 `ntp_sync_to_time()` 或开启 `RT_USING_NETUTILS` 后查 `ntp.h`。
> 没有网络/不想依赖 NTP 时，至少保证板子 `date` 显示的时间与真实时间偏差 < 5 分钟，否则讯飞签名鉴权失败。

## □ 第 7 步：准备测试音频（在 PC 上做）

阶段0 用预录 PCM 文件验证，不卡麦克风：

```bash
# 任意 wav/mp3 转成 16k/16bit/单声道 裸 PCM
ffmpeg -i 任意语音.wav -ar 16000 -ac 1 -f s16le pcm_test.raw

# 把 pcm_test.raw 传到板子文件系统根目录（DFS/elmfat 已开的前提下）
# 方式A：U盘/SD 拷进后挂到 /，确认存在 /pcm_test.raw
# 方式B：用 tftp/nfs 拉到 /
```

> 音频内容就念一句你后面想识别的命令词，例如「打开摄像头」「关闭报警」，方便对照。

## □ 第 8 步：上板验证（逐条在串口终端执行）

```bash
# 1) 以太网已 up（之前 RTSP 能推说明已通，再确认一次）
ifconfig
#    → 看到 eth0 有 IP（如 192.168.x.x）

# 2) 校时（若第5步已自动校时，可跳过，但建议确认）
ntp_sync
date
#    → 时间应接近真实时间

# 3) 确认测试音频在位
ls /pcm_test.raw

# 4) 触发一次识别
voice_test
```

**期望串口输出：**
```
[voice] captured 160000 bytes pcm, recognizing...
[xf] partial: 打开
[xf] FINAL: 打开摄像头
[voice] cmd: 打开摄像头
[voice] -> RELAY ON
```
同时讯飞控制台「实时用量」会 +1，这是调通的最直观旁证。

## 失败速查表

| 现象 | 原因 | 处理 |
|---|---|---|
| `voice_test` 直接报网络错 `-6` | 以太网未 up / DNS 不通 | `ifconfig` 看 IP；`ping iat-api.xfyun.cn` |
| 返回鉴权错误（`error 1xxxx` / 401） | 系统时间偏差大 | `date` 看时间，`ntp_sync` 校时 |
| 返回格式错误 | PCM 不是 16k/16bit/单声道 | 重做第 7 步 ffmpeg 参数 |
| 返回 `invalid appid` 等 | 凭证填错/不匹配 | 确认三个值都来自同一应用 MC632X |
| 编译报 `undefined reference to curl_*` | libcurl 没链上 | 确认 `PKG_USING_LIBCURL` 已开且 `make` 已拉包 |
| 编译报 `mbedtls` 相关缺失 | mbedtls 没开 | 确认 `PKG_USING_MBEDTLS` 已开 |
