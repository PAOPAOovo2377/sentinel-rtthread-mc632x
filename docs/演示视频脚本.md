# 演示视频脚本 · SENTINEL

**时长**：3 分 30 秒　|　**画幅**：1920×1080　|　**帧率**：30fps　|　**格式**：MP4 (H.264)

**拍摄原则**：全片不出现人脸特写以外的隐私信息；所有操作一次成功，失败镜头剪掉重来；网页画面录制时关闭浏览器书签栏，全屏录制。

## 三、旁白总稿（可直接照读，约 780 字）

> 这是一台不需要电脑就能独立工作的 AI 视觉终端。它只有一根电源线和一根网线，上电之后，自己完成全部初始化。
>
> 整机的核心是一颗高度集成的视觉 SoC。它把双路图像处理、神经网络加速、视频编码、音频编解码和以太网全部集成在片内。所以外围非常简洁：两颗摄像头、一片内存、一片 flash、一块屏、一个网口，就是全部。
>
> 软件分成五层。最底下是芯片厂商提供的驱动层，往上是 RT-Thread 实时内核和网络协议栈，再往上是算法层——人形检测模型和跟踪判定库，然后是八个业务服务线程，最上面是网页控制台和命令行。层与层之间单向依赖，业务代码不碰寄存器。
>
> 两个摄像头同时在线。左边这一路是高清实拍，专门给人眼看；右边这一路分辨率低一些，专门喂给神经网络。互不抢资源。
>
> 板载的神经网络加速器在跑人形检测。这些红框不是网页画的，是板子算出来之后传上去的。
>
> 画面里这条竖线就是警戒线。人只要走过去，板子立刻留一张现场图，同时记一条事件。注意看——图片里就是刚刚那一刻，不是几秒之后的画面。
>
> 证据可以翻页、可以单张删除、也可以一键清空。容量五十张，拍满了自动覆盖最旧的一张。
>
> 现场登记，不需要电脑。人站到镜头前，填个名字就建好档了。下次再出现，直接认出来。
>
> 现场环境不一样，画面参数可以直接在网页上调，实时生效。
>
> 除了点网页，还能直接说。说一句抓拍，它就抓一张。也支持语音对讲——在浏览器里说话，板子那边直接播出来。
>
> 这是运行时的资源占用。可以看到 CPU 大部分时间是空闲的——因为编码、推理、图像处理全部由硬件单元完成，CPU 只负责调度和搬数据。
>
> 看得见、认得准、记得住、说得出。一根网线，一个浏览器，就是全部。

## 五、常见翻车点

1. **网页画面糊**：浏览器缩放不是 100% 时截图会糊，录制前按 `Ctrl+0` 复位。
2. **越线不触发**：拍摄前先用 `trip` 命令确认警戒线位置，并把画面里的人形框调到能覆盖走道。
3. **相册里没有新图**：抓拍依赖编码器出流，**必须先把网页的"AI 主路"打开**（即先让 MJPEG 流跑起来），否则抓不到帧。
4. **对讲没声音**：Chrome 在非 HTTPS 页面默认不给麦克风权限，需要提前用启动参数把板端地址加入安全白名单。
5. **串口日志一闪而过**：录屏软件录串口窗口，或用终端的"记录日志"功能，后期再剪。
